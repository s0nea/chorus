# 001 — UI Unit Test Integration

## Context

The `ui/` project (Vue 3 + TypeScript + Vite) has ~125 components, 14 Pinia stores, 2 services, 2 composables, and 8 helper modules — with zero test coverage. Vitest, `@vue/test-utils`, and jsdom are already installed and configured but unused.

## Goal

Establish unit testing infrastructure, conventions, and initial coverage for the UI codebase. Enable developers to write and run tests consistently.

## Decisions

### Tech stack

| Concern | Choice | Rationale |
|---------|--------|-----------|
| Test runner | Vitest (already installed) | Official Vue recommendation, shares Vite config |
| Component mounting | `@vue/test-utils` (already installed) | Vue-recommended over `@testing-library/vue` |
| DOM environment | jsdom (already installed) | Already configured in `vitest.config.ts` |
| Store testing | `@pinia/testing` (to install) | Official Pinia test helper |
| HTTP mocking | `vi.mock` on axios/apiClient | Mock at HTTP layer, not at service layer |

### Mocking strategy

- **Mock:** axios/apiClient (HTTP layer), browser APIs, third-party libs, `useNotification` from clyso-ui-kit composables
- **Don't mock:** Vue framework features, Clyso UI Kit components, own models/interfaces, service classes, simple utilities

### Component test approach

- Pre-populate Pinia stores with test data via `@pinia/testing` — no HTTP mocking in component tests
- Only test components with meaningful logic (not pure layout/wrappers)
- Integration-style: don't mock child components

### What NOT to test

- Polling mechanics (`setTimeout` cycles) — test the fetch-and-transform logic only
- Vuelidate internals — test through store actions (valid state succeeds, invalid state stops)
- Framework behavior, lodash re-exports, trivial console wrappers

### Test file conventions

- Co-located: `src/<module>/__tests__/<name>.spec.ts`
- Already excluded from production build via `tsconfig.app.json`

### Coverage

No hard threshold. Establish patterns and infrastructure first, grow coverage organically.
